✊🤚✌️ Rock-Paper-Scissors
A simple Rock-Paper-Scissors game built with vanilla HTML, CSS, and JavaScript.
🎮 How to Play

Click one of the three buttons — Rock 👊, Paper 🤚, or Scissors ✌️
The computer picks a random choice
The result is displayed instantly
Scores are tracked for both you and the computer
